🏏 Cricket Analysis Dashboard
📌 Overview
The Cricket Analysis Dashboard is a data visualization project designed to analyze cricket match statistics, player performance, team wins, and match results. It presents key performance indicators (KPIs), charts, and interactive filters in a single dashboard to help users understand cricket data quickly and effectively.
🎯 Objectives
•	Analyze individual player performance and total runs scored.
•	Track match outcomes, including wins and losses.
•	Monitor wickets, catches, and total matches played.
•	Compare team performance using match-win statistics.
•	Provide interactive filters to explore cricket data by team, opponent, player, and result.

🖥️ Dashboard Layout
The dashboard is organized into four main sections:
1.	KPI Cards: Display overall cricket statistics.
2.	Player Analysis: Visualizes player-wise run performance.
3.	Match Results: Summarizes wins and losses.
4.	Team Analysis and Filters: Compares team wins and enables interactive data exploration.
