🏏 Cricket Analysis Dashboard
📌 Overview

The Cricket Analysis Dashboard is a data visualization project designed to analyze cricket match statistics, player performance, team wins, and match results. It presents key performance indicators (KPIs), interactive charts, and filters in a single dashboard to make cricket data easy to understand.

🎯 Objectives
Analyze player performance and total runs scored.
Track match outcomes, including wins and losses.
Monitor wickets, catches, and matches played.
Compare team performance using match-win statistics.
Explore cricket data using interactive filters.

📈 Key Insights
Approximately 22K total runs are displayed.
The dashboard reports 138 wins and 112 losses across 250 matches.
Player charts help compare individual run-scoring contributions.
Team charts highlight differences in match-win performance.
Interactive filters enable focused analysis of players, teams, opponents, and results.
🚀 How to Use
Clone or download this repository.
Open the Power BI dashboard file in Microsoft Power BI Desktop.
Review the KPI cards and performance charts.
Apply filters to explore specific players, teams, opponents, and results.
